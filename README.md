# Discrete Mathematics

A collection of interactive Jupyter notebooks covering the core topics of discrete mathematics, with executable Python examples, computational verification of theorems, and exercises.

## Contents

| # | Notebook | Topics |
|---|----------|--------|
| 01 | [Logic and Proofs](notebooks/01_logic_and_proofs.ipynb) | Propositional logic, truth tables, logical equivalences, proof techniques |
| 02 | [Set Theory](notebooks/02_set_theory.ipynb) | Set operations, power sets, Cartesian products, set identities |
| 03 | [Relations and Functions](notebooks/03_relations_and_functions.ipynb) | Binary relations, equivalence relations, injective/surjective/bijective functions |
| 04 | [Combinatorics](notebooks/04_combinatorics.ipynb) | Permutations, combinations, binomial theorem, Pascal's triangle, pigeonhole principle |
| 05 | [Graph Theory](notebooks/05_graph_theory.ipynb) | Graph representation, BFS, DFS, connectivity |
| 06 | [Number Theory](notebooks/06_number_theory.ipynb) | GCD, extended Euclidean algorithm, modular arithmetic, sieve of Eratosthenes |
| 07 | [Recursion and Recurrences](notebooks/07_recursion_and_recurrences.ipynb) | Recursive definitions, memoization, solving recurrences, induction |
| 08 | [Boolean Algebra](notebooks/08_boolean_algebra.ipynb) | Boolean functions, logic gates, normal forms, functional completeness |

## Getting Started

```bash
git clone https://github.com/HAYDARKILIC/discrete_mathematics.git
cd discrete_mathematics
pip install -r requirements.txt
jupyter notebook
```

Then open any notebook in the `notebooks/` folder and run the cells.

## Requirements

- Python 3.8+
- Jupyter
- Standard library only for most examples (no heavy dependencies)

See [`requirements.txt`](requirements.txt) for details.

## How to Use

Each notebook is self-contained and follows the same structure:

1. **Concept explanation** in Markdown with mathematical notation.
2. **Executable code** that implements and demonstrates the concept.
3. **Computational verification** of key theorems and identities.
4. **Exercises** for further practice at the end.
